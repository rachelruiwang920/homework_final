## 自撰對照

【自撰轉述】六篇可以沿「行動發生在什麼時候」排開。ReAct 的行動和推理在同一條生成裡輪流出現，環境把觀察塞回來。Toolformer 先讓模型學會在預測後面的 token 時決定 API。Reflexion 不改權重，而是把一次嘗試之後的語言反思存進記憶，給下一次用。AgentBench、SWE-bench 與 τ-bench 則幾乎不提出一種新的學習規則，它們規定什麼叫做做完：多個環境、程式庫測試，或對話結束時的資料庫狀態。

【自撰轉述】因此不能把「有工具」看成一種方法。有的論文把工具放進訓練，有的放進提示與環境的交替，有的放進評測介面。ReAct 摘要裡的 34% 與 10% 是對模仿學習和強化學習基線的絕對成功率差距，而且只提示一或兩個例子。這個數字不能拿去和 SWE-bench 的 1.96% 或 τ-bench 的小於 50% 相減。任務、工具、成功定義和模型都不一樣。

【自撰轉述】作者名單本身也提醒不要把會議頁和預印本看成同一份檔案。Toolformer 的會議頁比 arXiv v1 多了 Eric Hambro。Reflexion 的會議頁比 arXiv v4 少了 Edward Berman。SWE-bench 的題名在 Github / GitHub、Real-world / Real-World 上不一致，作者縮寫的句點也不一致。這些差異都留在來源檔，不在表格裡被抹平。

## 為什麼第二部分做 ReAct 的結構

【自撰轉述】第二部分要的是一個能在離線環境裡跑完的工具迴圈：搜尋、讀取至少三份、寫出有引用的簡報，並由驗證器重算區間與雜湊。ReAct 的論文正好把這個外形寫清楚：模型產生推理和行動，環境產生觀察。Toolformer 的決定性步驟是自監督訓練，沒有權重更新就不再是那篇方法。Reflexion 的決定性步驟是跨試次的語言記憶，單一條軌跡覆蓋不了。評測論文適合放在對照裡，說明「完成」後來被定義成環境狀態，但不適合當成這次要再現的迴圈本身。

這個選擇的代價是：做出來的程式只保留迴圈外形和證據檢查，不保留論文的模型、維基百科 API、HotpotQA、FEVER、ALFWorld 或 WebShop。範圍對照見 `reports/02-scope.md`。
