# 原方法與這次簡化的範圍

這次是結構教學用的簡化，不是 ReAct 論文的複現，也不是任何基準的重跑。第二部分配分裡的「與原論文結果復現度」佔該部分 30%。本作業不把這一項說成達標：Thought、Action、Observation 的外形對上了，HotpotQA、FEVER、ALFWorld、WebShop 的論文數字沒有重測。

| 項目 | 論文中的 ReAct | 本作業 |
| --- | --- | --- |
| 誰產生 Thought 與 Action | 被提示的語言模型 | 確定性腳本。模板句寫明不是模型輸出 |
| 觀察從哪裡來 | 維基百科 API，或 ALFWorld、WebShop 等環境 | 自建來源包。search 做整段錨點比對，read 讀本地檔 |
| 軌跡外形 | 模型產生 Act、Thought，環境產生 Obs | 保留 Thought、Action、Observation 三欄，但 Thought 是模板 |
| 成功怎麼算 | HotpotQA、FEVER、ALFWorld、WebShop 上的任務指標 | 自建驗證器檢查簡報引用的位元組區間與 SHA-256 |
| 要不要 GPU 或 API | 論文實驗使用大型語言模型 | 不需要。標準庫即可 |
| 論文報告的 34% 與 10% | 摘要頁所寫，相對模仿學習與強化學習的絕對差距 | 只當文獻數字。本作業沒有重測 |

論文裡和這次迴圈直接對應的一句是：

> trajectories generated by the model (Act, Thought) and the environment (Obs).

【自撰轉述】這句支持「軌跡分成模型側與環境側」。它不支持把本作業的腳本輸出說成 PaLM 或其他模型的軌跡。ALFWorld 與 WebShop 的 34% 與 10% 也只留在文獻表，不進入 `evaluation.csv`。

本作業自己的測量只有工具呼叫次數、證據槽覆蓋、引用是否通過，以及兩次重跑是否得到相同位元組。這些數字見 `reports/03-analysis.md` 與 `comparison-evaluation.csv`。
