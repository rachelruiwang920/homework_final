本檔由確定性執行器寫出，不是教師評語，也不是模型輸出。
來源依使用者指示自行選定。驗證器是自建的。未宣稱通過教師驗證器。

- 步數上限：3
- 已執行工具呼叫：3
- 停止原因代碼：budget_exhausted

工具迴圈在寫完簡報之前用盡步數。
下面這個動作是同一政策在停下來之後會做的下一步，它沒有被執行，也不在 trajectory.jsonl 裡。

```
{"arguments": {"source_id": "toolformer_2023"}, "executed": false, "not_executed": true, "thought": "【腳本模板，非模型輸出】仍有證據槽的錨點沒有在已讀文字中出現。依檢索排序讀取下一個尚未讀過的候選。", "tool": "read"}
```

因此這個條件沒有最終簡報。驗證器會因為缺少簡報與未完成引用而不通過。
